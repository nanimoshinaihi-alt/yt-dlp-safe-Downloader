# yt-dlp Safe Downloader (パス長制限回避 一括動画ダウンロードツール)

QNAP (NAS) や Windows のパス長制限 (MAX_PATH / UTF-8 バイト数制限) を回避し、見栄えの良いファイル名で動画を一括ダウンロードする GUI アプリケーションです。

---

## 🌟 主な特徴

1. **パス長制限 (240バイト) の自動回避**
   - 保存先フルパスの UTF-8 バイト数を動的に計算し、マルチバイト文字（日本語や絵文字等）が途中で途切れることなく安全に切り詰めます。
2. **TVerRec 準拠のスマート命名規則**
   - **X (x.com) / TikTok / Instagram**: `[サイト名] - [日付] - [アカウント名] - [ポスト内容].mp4`
   - **YouTube / その他**: `[日付] - [チャンネル名] - [動画タイトル].mp4`
   - 切り詰め結果で同名になった別動画は自動で `(1)`, `(2)` のナンバリングが付与されます。
3. **改行区切りによる複数 URL 一括順次ダウンロード**
   - 入力欄に URL を改行で複数並べるだけで、上から順番に自動でダウンロードします。
   - ダウンロード完了時、URL 入力欄は自動でクリアされます。
4. **yt-dlp の起動時自動アップデート**
   - TikTok や各 SNS の仕様変更に自動追従するため、アプリ起動時に `yt-dlp` の最新版チェック＆更新をバックグラウンドで実行します。
5. **設定と保存先の自動記憶**
   - 前回の保存先フォルダや画質・フォーマット設定は `config.json` に記憶され、次回起動時に自動復元されます。
   - 保存先フォルダ内に余計な管理ファイルを作成せず、履歴はアプリ直下に集約管理されます。

---

## 💻 動作環境

* **OS**: Windows 10 / 11
* **Python**: 3.10 以上

---

## 🚀 導入手順 (別の PC や新規環境)

1. **Python のインストール** (未導入の場合)
   - [Python 公式サイト](https://www.python.org/downloads/) から Python をダウンロードしてインストールします。
   - ⚠️ **重要**: インストール画面の最初にある **「Add python.exe to PATH」** に必ずチェックを入れてください。

2. **フォルダの配置**
   - `yt-dlp-GUI` フォルダを PC の任意の場所に配置します。

3. **起動**
   - フォルダ内の **`GUI起動.bat`** をダブルクリックしてください。
   - 初回起動時、必要なライブラリ (`yt-dlp`, `customtkinter`) が無ければ**自動的にセットアップされて起動**します。

---

## 📖 使用方法

1. **`GUI起動.bat`** をダブルクリックしてアプリを起動します。
2. **「動画 URL」** 欄に、ダウンロードしたい動画の URL を入力します（改行で複数並べて貼り付け可能）。
3. 必要に応じて **「保存先フォルダ」** の「参照...」ボタンから保存先（QNAP 共有フォルダやローカルフォルダ）を指定します。
4. **「一括ダウンロード開始」** ボタンをクリックします。

## ❓ トラブルシューティング

* **起動バッチを押しても一瞬で画面が消える**
  * Python がインストールされていないか、PATH の設定が有効になっていない可能性があります。Python の再インストールをお試しください。
* **Firefox クッキーエラーが出る**
  * Firefox が起動中でクッキーファイルが一時ロックされている可能性があります。アプリは自動的に「クッキーなし」で安全に再試行を行います。
