# yt-dlp Safe Downloader (パス長制限回避 一括ダウンロードツール)

QNAP (NAS) や Windows のパス長制限 (MAX_PATH / UTF-8 バイト数制限) を回避し、安定して動画を一括ダウンロードできる GUI アプリケーションです。

---

## 📌 主な機能

1. **パス長制限 (240バイト) の自動回避**
   - 保存先フルパスの UTF-8 バイト数を動的に計算し、マルチバイト（日本語・絵文字）を切断することなく安全に切り詰めます。
2. **TVerRec 準拠のスマート命名規則**
   - **X (x.com) / TikTok / Instagram**: `[サイト名] - [日付] - [アカウント名] - [ポスト内容].mp4`
   - **YouTube / その他**: `[日付] - [チャンネル名] - [動画タイトル].mp4`
   - 切り詰め結果で同名になった場合は `(1)`, `(2)` のナンバリングが付与されます。
3. **改行区切りによる複数 URL 一括ダウンロード**
   - 入力欄に URL を改行で並べるだけで、順に自動ダウンロードします。
   - ペースト時に自動で改行が入るため、連続コピペも快適です。
4. **リアルタイムフォント切替機能**
   - ドロップダウンからお好みのフォント（メイリオ、游ゴシック UI、BIZ UDPゴシック、Segoe UI、MS ゴシック等）を選んで即座に切替可能です。
5. **yt-dlp の起動時自動アップデート**
   - 各 SNS の仕様変更に自動追従するため、アプリ起動時に `yt-dlp` の最新チェック＆更新をバックグラウンドで自動実行します。

---

## 💻 動作環境

* **OS**: Windows 10 / 11
* **Python**: 3.10 以上 (未導入の場合は下記参照)

---

## 🔰 Python が入っていない PC への導入手順 (完全ガイド)

別の PC や新規環境で起動する場合、Python が未導入であれば以下の手順で導入してください。

### 【ステップ 1】Python インストーラーのダウンロード
1. ブラウザで [Python 公式サイト](https://www.python.org/downloads/) にアクセスします。
2. **「Download Python 3.12.x」**（黄色いボタン）をクリックしてインストーラーをダウンロードします。

### 【ステップ 2】Python のインストール（※超重要チェックあり！）
1. ダウンロードした `python-3.12.x-amd64.exe` をダブルクリックして実行します。
2. ⚠️ **【最重要】画面の一番下にある以下の項目に「必ずチェック」を入れてください！**
   * ☑ **`Add python.exe to PATH`**
   *(※これにチェックを入れないと `GUI起動.bat` が Python を認識できなくなります)*
3. 画面中央上の **「Install Now」** をクリックします。
4. 「Setup was successful」と表示されたら「Close」を押して閉じます。

### 【ステップ 3】アプリの起動
1. 本ツール（`yt-dlp-GUI` フォルダ）を任意の場所に配置します。
2. フォルダ内の **`GUI起動.bat`** をダブルクリックします。
3. 初回起動時は、自動的に必要なライブラリ (`yt-dlp`, `customtkinter`) がダウンロード・セットアップされ、数秒後に画面が立ち上がります。

---

## 🚀 基本使用方法

1. **`GUI起動.bat`** をダブルクリックしてアプリを起動します。
2. **「動画 URL」** 欄に、ダウンロードしたい URL を入力（貼り付け）します。
3. 必要に応じて **「保存先フォルダ」** の「参照...」ボタンから保存先（QNAP 共有フォルダ等）を指定します。
4. **「一括ダウンロード開始」** ボタンをクリックします。
